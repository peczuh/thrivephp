    Class ThriveData\ThrivePHP\WebDriver\Element

    A selector-backed target or an exact DOM node in a captured window/frame. Searches resolve afresh per operation; resolve() freezes the resulting node. Ordinary readers wait for presence, then read once. Exact nodes never re-find. Conditions return bool by default. $is=false negates the predicate; $assert=true records one result and returns this element. $stop=false continues after a failed assertion under an active Test; outside a Test, assertion failures always throw. Null $wait checks queries once and polls assertions. Explicit $wait overrides this. Condition $timeout is positive, finite milliseconds, null for assertionTimeout, ignored without waiting. One budget covers lookup and evaluation at pollInterval. Commands retain their own timeouts. Context and unrelated driver errors propagate. Absence makes present()/visible() false. Other one-shot conditions require a node; waiting conditions remain unsatisfied while it is missing, even with $is=false.
