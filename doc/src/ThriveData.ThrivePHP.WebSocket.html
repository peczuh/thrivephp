    Class ThriveData\ThrivePHP\WebSocket

    Synchronous RFC 6455 text client using PHP streams; wss:// requires OpenSSL. No extensions or subprotocols are negotiated. Connection/protocol failures and operation timeouts close the socket and throw RuntimeException: a partially transferred frame cannot safely be retried. Invalid arguments instead throw InvalidArgumentException without closing an established connection.

    Example (requires a running WebSocket echo server):

    $socket = new \ThriveData\ThrivePHP\WebSocket('ws://localhost:8080', timeout: 10);
try {
    $socket->send('Hello');
    $reply = $socket->receive(); // Returns "Hello"; null means the peer closed normally.
} finally {
    $socket->close();
}

    Protocol reference: https://www.rfc-editor.org/rfc/rfc6455
