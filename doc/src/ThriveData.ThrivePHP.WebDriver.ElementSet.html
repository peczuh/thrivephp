    Class ThriveData\ThrivePHP\WebDriver\ElementSet

    implements IteratorAggregate<int, Element>, Countable

    A collection search, or an explicitly constructed fixed-membership snapshot. Searches count current matches and create positional targets with first()/get(). all() and iteration materialize one snapshot of exact nodes, which may become stale. Empty sets are truthy objects; use count() or countEquals() to check membership.
