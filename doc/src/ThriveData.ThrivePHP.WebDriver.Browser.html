    Class ThriveData\ThrivePHP\WebDriver\Browser

    One browser session using classic HTTP WebDriver and optional WebDriver BiDi. The browser driver must already be running. PHP streams handle HTTP; WebSocket handles BiDi. Use WebDriver for local discovery and owned driver services; this class also connects directly to externally managed endpoints. Commands return their receiver for chaining; queries return values or objects. Window operations target the current window. open() returns and selects a new Window; operations on saved Window/Element objects select their owning context.

    Example (requires GeckoDriver listening on port 4444):

    $driver = new \ThriveData\ThrivePHP\WebDriver\Browser('http://localhost:4444', 'firefox', bidi: true);
try {
    $driver->resize(1440, 900)->navigate('data:text/html,<title>Example</title><input id="name">');
    $input = $driver->wait(function ($driver) {
        $element = $driver->find('#name');
        return $element->visible() && $element->enabled() ? $element : false;
    }, timeout: 10000);
    $input->clear()->type('Hello')->key(\ThriveData\ThrivePHP\WebDriver\Browser::TAB);
    $value = $driver->script('return arguments[0].value;', arguments: [$input]);
    $title = $driver->title();
    $contexts = $driver->command('browsingContext.getTree');
    $inputs = $driver->findAll('input');
    $png = $driver->screenshot()->data(); // Decoded PNG bytes.
} finally {
    $driver->quit();
}

    Classic commands work with Safari, Chrome, and Firefox. BiDi must be requested explicitly and supported by the driver. Subscribe with subscribe(['log.entryAdded']) before retrieving console and JavaScript error events with event(). Call quit() explicitly to end the remote session, including after exceptions.

    Protocols: https://www.w3.org/TR/webdriver/ and https://www.w3.org/TR/webdriver-bidi/

    public cookie( string $name, ?string $value = null, ?string $domain = null, string $path = '/', bool $secure = false, bool $httpOnly = false, ?string $sameSite = null, ?int $expiry = null, ): string|self
    Read or set a cookie for the active document. Navigate to the target website first; WebDriver rejects unrelated domains…

    Read or set a cookie for the active document. Navigate to the target website first; WebDriver rejects unrelated domains and cookie-averse pages such as data: URLs.

    Omit $value or pass null to return the named cookie's string value. Missing cookies throw the driver's error. Use cookies() to retrieve full cookie fields. Pass a string (including '' or '0') to add/replace the cookie and return this browser for chaining.

    Optional arguments when setting a cookie (ignored when reading):

    • $domain: null uses the active document's domain.
    • $path: cookie URL path scope; defaults to '/'.
    • $secure: send only over secure connections; defaults to false.
    • $httpOnly: prevent JavaScript access; defaults to false.
    • $sameSite: 'Strict', 'Lax', or 'None'; null leaves the browser's default.
    • $expiry: expiration as Unix seconds, not milliseconds or a duration. null creates a session cookie. Null optional arguments are omitted on the wire.
    $browser->navigate('https://example.com')->cookie(
    name: 'theme',
    value: 'dark',
    secure: true,
    sameSite: 'Lax',
    expiry: time() + 86400,
);
$theme = $browser->cookie('theme'); // 'dark'

    Invalid cookie fields or domains throw the driver's error.

    public pdf( string $orientation = 'portrait', float $scale = 1, bool $background = false, float $pageWidth = 21.59, float $pageHeight = 27.94, float $marginTop = 1, float $marginBottom = 1, float $marginLeft = 1, float $marginRight = 1, array $pageRanges = [], bool $shrinkToFit = true, ): PDF
    Capture a PDF of the current window/frame immediately using W3C print options. Use ->data() for decoded bytes or ->save…

    Capture a PDF of the current window/frame immediately using W3C print options. Use ->data() for decoded bytes or ->save('page.pdf') to write them. Support depends on the browser/driver; unsupported-command errors propagate.

    Optional named arguments:

    • $orientation: 'portrait' (default) or 'landscape'.
    • $scale: 0.1 to 2, default 1; $background: include background graphics, default false.
    • $pageWidth/$pageHeight: paper dimensions in cm, defaults 21.59 x 27.94; minimum 2.54 / 72 cm each. Landscape swaps the dimensions.
    • $marginTop/$marginBottom/$marginLeft/$marginRight: nonnegative cm, default 1 each.
    • $pageRanges: list of one-based page integers or strings such as '3-5', '-2', or '4-'; default [] includes every page.
    • $shrinkToFit: fit content to the paper width, default true.
    $browser->pdf(
    background: true,
    pageWidth: 21, pageHeight: 29.7,
    marginLeft: 0.5, marginRight: 0.5,
    pageRanges: [1, '3-5'],
)->save('page.pdf');

    public actions(array $sources): self
    Perform W3C keyboard, pointer, or wheel input sources, retaining held input state. Pass the source list (not an outer…

    Perform W3C keyboard, pointer, or wheel input sources, retaining held input state. Pass the source list (not an outer actions object); call releaseActions() when done. Source IDs let subsequent calls continue the same keyboard or pointer sequence. Each source is ['id' => string, 'type' => 'key'|'pointer'|'wheel'|'none', 'actions' => list of action arrays]. Sources run together in ticks by list index. Pointer sources optionally include parameters: ['pointerType' => 'mouse'|'pen'|'touch'] (default mouse). Action types and fields:

    • pause: optional duration, default 0; valid on every source ('none' only pauses).
    • keyDown/keyUp: value is one Unicode character or a Browser key constant.
    • pointerMove: integer x/y, optional duration and origin ('viewport' by default, 'pointer', or an Element from the current window/frame).
    • pointerDown/pointerUp: integer button (0 left, 1 middle, 2 right).
    • scroll (wheel): integer x/y/deltaX/deltaY, optional duration and origin ('viewport' by default or an Element from the current window/frame). Durations are nonnegative integer milliseconds; omitted move/scroll durations use the tick duration (the longest duration across sources in that tick). Coordinates/deltas are CSS pixels. Driver validation/support errors propagate. Cycles or nesting beyond 64 levels throw InvalidArgumentException. See also Window::actions().
    $button = $browser->find('button');
try {
    $browser->actions([[
        'type' => 'pointer', 'id' => 'mouse',
        'parameters' => ['pointerType' => 'mouse'],
        'actions' => [
            ['type' => 'pointerMove', 'origin' => $button, 'x' => 0, 'y' => 0],
            ['type' => 'pointerDown', 'button' => 0],
            ['type' => 'pointerUp', 'button' => 0],
        ],
    ]]);
} finally {
    $browser->releaseActions();
}

    public script(string $script, bool $async = false, array $arguments = [], bool $inject = false): mixed
    Execute JavaScript in the current window/frame and return its JSON-decoded result. $arguments are positional JavaScript…

    Execute JavaScript in the current window/frame and return its JSON-decoded result. $arguments are positional JavaScript arguments and may contain Element objects in nested arrays. Returned DOM elements are converted to Element objects. Cyclic arguments or nesting beyond 64 levels throw InvalidArgumentException.

    PHP blocks until execution completes in either mode. With $async = true, WebDriver appends a completion callback as the final JavaScript argument. Call it with the result to complete the waiting PHP call. Returning from the JavaScript function without signaling completion does not finish the wait. A timeout or execution error throws an exception.

    Calling the callback signals completion of this invocation; other outstanding JavaScript requests or timers may still be running.

    With $inject, append an inline script containing the source (without script tags) and return null. Execution is subject to CSP; insertion does not guarantee success. Injection rejects $async=true and nonempty $arguments.

    $driver->scriptTimeout(5);
$result = $driver->script(
    'const done = arguments[arguments.length - 1]; setTimeout(() => done(42), 100);',
    async: true,
);

    The script's browser timeout plus the constructor's I/O allowance is used for this HTTP request. If the browser timeout is disabled (null), only the finite constructor timeout applies; an indefinitely running script is not awaited forever.
