    Class ThriveData\ThrivePHP\WebDriver\WebDriver

    Local dependency inventory and an owned WebDriver service for test scaffolding. bootstrap() only inspects installed software. Construction starts a driver; browser() creates one session at a time, and stop() cleans up both resources. Application bootstrap is responsible for installing browsers and drivers.

    $inventory = WebDriver::bootstrap(); // JSON-compatible stdClass, no provisioning.
$driver = new WebDriver(browser: 'firefox');
try {
    $browser = $driver->browser(headless: true);
    $browser->navigate('https://example.com');
} finally {
    $driver->stop();
}

    Start a local service for chrome, chromium, firefox, safari, or safaripreview. Null selects Chrome, Chromium, Firefox, Safari Technology Preview, then Safari; a failure after selection never changes browser. Discovery uses local executables, not bootstrap reports or downloads.

    $port: null prefers Safari/Preview 4445, Chrome/Chromium 9515, or Firefox 4444; an occupied preferred port logs a warning and selects a free port. An explicitly requested port (1–65535) is mandatory. Services bind to loopback only. $startupTimeout: positive seconds to start the service after discovery. $shutdownTimeout: positive seconds to terminate its process; HTTP session cleanup uses that session's own command timeout. No browser session starts here.

    public static bootstrap(): stdClass
    Inspect macOS, Debian Linux, FreeBSD, or Windows without installing software, fetching release metadata, starting…

    Inspect macOS, Debian Linux, FreeBSD, or Windows without installing software, fetching release metadata, starting services, or creating browser sessions. Search conventional locations and PATH, with one entry per browser type.

    Returns {ready: bool, platform: {os, architecture, distribution}, browsers: {chrome, chromium, firefox, safari, safaripreview}}. Each browser has name, ready, path, version, reason, message, and a nested driver with the same component fields. Paths/versions/reasons/messages are null when unavailable or inapplicable.

    Component ready is true, 'unprovisioned' (missing), 'unsupported' (platform), 'notready' (known execution failure), or 'unknown' (discovery/probe failure). Overall ready requires at least one pair whose two states are literally true. A successful version/metadata check does not certify compatibility, Safari authorization, display availability, or session creation. Discovery failures are data; programming errors propagate. Serialize with json_encode().

    public browser( bool $headless = true, bool $bidi = false, float $timeout = 10, array $capabilities = [], float $waitTimeout = 5000, float $assertionTimeout = 5000, float $pollInterval = 500, ): Browser
    Create the sole active owned session. After quit() or closing its last window, another session can be created. …

    Create the sole active owned session. After quit() or closing its last window, another session can be created. $headless defaults to true and adds the browser's headless flag. Safari and Preview require headless: false.

    $timeout is positive seconds for Browser's command I/O, not service startup. $waitTimeout, $assertionTimeout and $pollInterval configure polling in positive, finite milliseconds. $bidi requests BiDi support. $capabilities accepts browser-specific options; arguments/preferences are retained, but the detected binary cannot be replaced. Failure during session creation stops the owned service: a lost response may have left a remote session that this client cannot identify for deletion. Assertions report automatically to the active Test and stop on failure by default. Conditions query by default; $assert=true records a result, and $stop=false continues after mismatches. Outside Test::run(), failures throw. Assertions retry by default; $wait=false checks once.

    Quit the owned session, then terminate and reap the owned driver even if HTTP cleanup fails. Explicit calls throw after attempting cleanup; shutdown logs errors instead. Failed termination keeps the process handle for retry. Repeated calls after successful termination are harmless. Returns this runtime.
