    Class ThriveData\ThrivePHP\WebDriver\Window

    One browser window/tab and its selected frame. Commands select this window automatically and return it for chaining. Elements retain the frame path from their lookup, even after this window selects another frame. Frame indices are positional; use frame Elements when a stable frame identity is required. Top-level queries and commands do not restore frames; later frame-dependent operations still restore the saved selection. Navigation resets that selection.

    public cookie( string $name, ?string $value = null, ?string $domain = null, string $path = '/', bool $secure = false, bool $httpOnly = false, ?string $sameSite = null, ?int $expiry = null, ): string|self
    Read or set a cookie for the active document. Navigate to the target website first; WebDriver rejects unrelated domains…

    Read or set a cookie for the active document. Navigate to the target website first; WebDriver rejects unrelated domains and cookie-averse pages such as data: URLs.

    Omit $value or pass null to return the named cookie's string value. Missing cookies throw the driver's error. Use cookies() to retrieve full cookie fields. Pass a string (including '' or '0') to add/replace the cookie and return this window for chaining.

    Optional arguments when setting a cookie (ignored when reading):

    • $domain: null uses the active document's domain.
    • $path: cookie URL path scope; defaults to '/'.
    • $secure: send only over secure connections; defaults to false.
    • $httpOnly: prevent JavaScript access; defaults to false.
    • $sameSite: 'Strict', 'Lax', or 'None'; null leaves the browser's default.
    • $expiry: expiration as Unix seconds, not milliseconds or a duration. null creates a session cookie. Null optional arguments are omitted on the wire.
    $window->navigate('https://example.com')->cookie(
    name: 'theme',
    value: 'dark',
    secure: true,
    sameSite: 'Lax',
    expiry: time() + 86400,
);
$theme = $window->cookie('theme'); // 'dark'

    Invalid cookie fields or domains throw the driver's error.

    public snapshot(): Snapshot
    Capture this window's selected HTML document/frame, using a detached DOM copy. Remove script elements, declare UTF-8,…

    Capture this window's selected HTML document/frame, using a detached DOM copy. Remove script elements, declare UTF-8, and replace base elements with document.baseURI so relative resources keep their original resolution, including any existing base. Preserve the doctype and serialized markup, not JavaScript memory, canvas pixels, shadow trees or property-only form state. Resources and child frames are not bundled. Script removal is not HTML sanitization; inline event handlers remain. Use ->data() or ->save('page.html'), even after session cleanup. Driver errors propagate.

    public pdf( string $orientation = 'portrait', float $scale = 1, bool $background = false, float $pageWidth = 21.59, float $pageHeight = 27.94, float $marginTop = 1, float $marginBottom = 1, float $marginLeft = 1, float $marginRight = 1, array $pageRanges = [], bool $shrinkToFit = true, ): PDF
    Capture a PDF of the selected browsing context immediately. Use ->data() for decoded bytes or ->save('page.pdf') to…

    Capture a PDF of the selected browsing context immediately. Use ->data() for decoded bytes or ->save('page.pdf') to write them. Browser/driver support varies; unsupported commands and invalid options propagate the driver's error.

    Optional named arguments use W3C print settings:

    • $orientation: 'portrait' (default) or 'landscape'.
    • $scale: 0.1 to 2, default 1.
    • $background: include background graphics, default false.
    • $pageWidth/$pageHeight: paper dimensions in cm, defaults 21.59 x 27.94. Each must be at least 2.54 / 72 cm. Landscape swaps the dimensions.
    • $marginTop/$marginBottom/$marginLeft/$marginRight: nonnegative cm, default 1 each.
    • $pageRanges: list of one-based page integers or range strings, e.g. [1, '3-5']; default [] prints all pages. Open ranges such as '-2' and '4-' are supported.
    • $shrinkToFit: fit content to the paper width, default true.
    $window->pdf(
    background: true,
    pageWidth: 21, pageHeight: 29.7,
    marginLeft: 0.5, marginRight: 0.5,
    pageRanges: [1, '3-5'],
)->save('page.pdf');

    public actions(array $sources): self
    Perform W3C input sequences in the selected frame. Pass a list of source arrays, not an outer ['actions' => ...]…

    Perform W3C input sequences in the selected frame. Pass a list of source arrays, not an outer ['actions' => ...] wrapper. Each source requires a string id, a type ('key', 'pointer', 'wheel', or 'none'), and an ordered actions list. IDs continue earlier sequences; held keys/buttons persist until released or releaseActions(). Sources run together in ticks, pairing actions at the same list index.

    Action arrays require type plus these fields (durations are nonnegative integer milliseconds; coordinates and scroll deltas are integer CSS pixels):

    • Any source: ['type' => 'pause', 'duration' => 100]; duration defaults to 0.
    • key: keyDown/keyUp with value: a single Unicode character or Browser key constant.
    • pointer: pointerMove with x, y, optional duration, and origin ('viewport' by default, 'pointer', or an Element in this window/frame); pointerDown/pointerUp with button (0 left, 1 middle, 2 right). Optional source parameters: ['pointerType' => 'mouse'|'pen'|'touch']; default mouse.
    • wheel: scroll with x, y, deltaX, deltaY, optional duration, and origin ('viewport' by default or an Element in this window/frame).
    • none: pause only. Driver-specific support/validation errors propagate. Omitted move/scroll durations use the tick duration (the longest duration across sources in that tick). Cyclic sources or nesting beyond 64 levels throw InvalidArgumentException.
    $button = $window->find('button');
try {
    $window->actions([[
        'type' => 'pointer', 'id' => 'mouse',
        'parameters' => ['pointerType' => 'mouse'],
        'actions' => [
            ['type' => 'pointerMove', 'origin' => $button, 'x' => 0, 'y' => 0, 'duration' => 100],
            ['type' => 'pointerDown', 'button' => 0],
            ['type' => 'pointerUp', 'button' => 0],
        ],
    ]]);
} finally {
    $window->releaseActions();
}

    public tap(string ...$keys): self
    Tap one key or chord at current focus. Press in argument order, release in reverse, then clear input-source state,…

    Tap one key or chord at current focus. Press in argument order, release in reverse, then clear input-source state, including after a failed sequence. Never replay input. tap(Browser::META, Browser::SHIFT, 'a') holds both modifiers for the letter's keydown. Each key is one Unicode character or Browser key constant. For sequential text use Element::type()/key(); tap('a', 'b') holds both letters. No arguments is a no-op.
