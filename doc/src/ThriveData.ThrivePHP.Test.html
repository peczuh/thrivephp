    public run( list<string> $names = [], ?int $workers = null, ?string $browser = null, ?bool $headless = null, list<string> $selectors = [], ?string $title = null, array $capabilities = [], ): int
    Run checks and print results. Return 0 only when every selected check passes. Files receive $test in their loading…

    Run checks and print results. Return 0 only when every selected check passes. Files receive $test in their loading scope and return a Test\Suite or a callable. Legacy callables accept this Test; their return values are ignored. Register this instance as the process-wide active recorder during each check, restoring the previous recorder afterward. Assertion failures stop the current callable check, case body, or hook. Suite cleanup always runs; later cases follow skipRemainingOnFailure, which defaults to true for browser suites and false otherwise.

    Null workers prefers two parallel processes, falling back to serial for Safari. Explicit workers > 1 requires a parallel-capable selected browser; 1 runs in-process. Browser and headless apply to every managed SuiteBrowser in this run. Null headless uses test.browser.headless, then true; explicit booleans override settings. Capabilities replace matching test.browser.capabilities keys before suite configure() runs. Title identifies the project; null uses test.project, then the root Composer package name. Selected suite paths must have safe components and be unique ignoring case.

    Paths relative to checks/, without .php; empty selects all.
    $selectors
